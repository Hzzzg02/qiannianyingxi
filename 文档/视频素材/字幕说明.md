## 这一版字幕的做法

按**画面操作**贴字幕：每条字幕绑定视频里的一个具体动作时刻，滑到某屏就说"来到X页"，点分类就逐个报名字。这一版（v4）读完全站页面 + 逐帧核过视频后重写。

- 字幕文件：`网站介绍字幕.srt`（97 条）
- 生成脚本：`_tmp/make_srt_v4.py`（改字幕时间点/文字后重跑即可）
- 成片：桌面 `屏幕录制 2026-11-18 104934_带字幕.mp4`
- 原片备份：`屏幕录制-原始备份.mp4`（原件未动）

## v3 修正的三个关键问题

1. **开头对话框（影窗）**：3–5s 用户开始点输入框时就介绍——"中间这个对话框是网站的影窗，皮子怎么选、刀怎么走，都能问影窗里的说戏人"。原先要到 8s 才泛泛说"问答入口"，晚了。
2. **影窗问答页**：10s 视频从首页跳进 chat.html（深色对话页，顶部"影窗问答/说戏人"），字幕明确说"点『进影窗问答』，来到说戏人的对话页"，13s 讲说戏人作答、16s 讲接着追问。原先完全漏掉了这个页面切换。
3. **六色屏分类顺序与点击时刻**：页面实际顺序是**头茬 / 砌末 / 衬景 / 坐骑 / 身段 / 戳子**（首页 index.html 的 pcard 顺序）。逐帧确认用户约每 1.5 秒从左到右点一个，字幕对准点击时刻 22 / 23.5 / 25 / 26.5 / 28 / 29.5 秒。原先从模糊缩略图读错了顺序，把头茬放到了倒数第二。

## 关键概念（读网站页面所得）

- **影窗**：首页首屏 AI 问答区（"问这座影窗里的说戏人"），点进去是 `chat.html`「影窗问答」，对话框里是"说戏人"。影窗也指幕布本身，旧称"亮子"。
- **影箱六器**：头茬（韦陀头，一颗头定行当）、砌末（椅子）、衬景（莲花台）、坐骑（龙首驹）、身段（孙悟空整身）、戳子（团花衫身子）。首页六色屏 + 影藏页都围绕这六件。
- **影藏页藏品库**：两排筛选——类别（头茬82/靴子71/戳子35/道具33/衬景30/动物28/影卷21）+ 地域（湖北/陕西/甘肃/浙江…13地）。
- 各页定位见网站各 html 的 description。

## 怎么改

1. 改 `_tmp/make_srt_v4.py` 里的 `CUES` 列表，格式 `(起始秒, 字幕文字, 最长显示秒数)`。
2. 运行 `python _tmp/make_srt_v4.py` 重新生成 SRT（同时写入 `网站介绍字幕.srt` 和 `sub.srt`）。
3. 重新烧录：把 `sub.srt` 复制到一个无中文路径的目录（如 `C:/vsrt/`），`cd` 到该目录后执行：
   `ffmpeg -i 原片 -vf "subtitles=sub.srt:force_style='FontName=Microsoft YaHei,FontSize=30,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,BorderStyle=1,Outline=2,Shadow=1,Alignment=2,MarginV=45'" -c:v libx264 -preset veryfast -crf 22 -c:a copy 输出`
   注意：字幕路径含中文或盘符冒号会让 subtitles 滤镜解析失败，务必用相对文件名并先 cd。

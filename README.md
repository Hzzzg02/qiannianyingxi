## 一、快速开始

### 只想看页面

双击 `index.html` 就能打开，不需要安装任何东西。页面、动效、专题内容都能正常浏览。

需要后端的功能（登录、社区、AI 问答、影偶出图）在 `file://` 下用不了：问答会提示未接入，影偶出图无法提交。要看完整功能，用下面的本地服务器方式。

### 本地完整运行

需要 Node.js 20 或更高版本，无需 `npm install`，没有第三方依赖。

```bash
# 终端 1：起后端 API（127.0.0.1:3100）
node server/server.js

# 终端 2：起静态站 + API 反代（127.0.0.1:8092）
node server/dev.js
```

浏览器打开 <http://127.0.0.1:8092>。

端口可用环境变量改：`PORT` 改后端端口，`DEV_PORT` 改前端端口，`API_PORT` 告诉前端反代到哪个后端端口。

### 配置自己的 AI Key（可选）

不开 AI 也能逛站内所有内容。要接自己的模型，复制模板填 Key：

```bash
cp server/config/deepseek.example.json server/config/deepseek.json
cp server/config/zhipu.example.json   server/config/zhipu.json
cp .env.example .env
```

也可以用环境变量，例如 `QN_DEEPSEEK_KEY`、`QN_ZHIPU_KEY`、`QN_MAIL_MODE=log`。配置查找顺序见[配置说明](#配置与环境变量)。

> `server/config/*.json`、`server/data/db.json`、`uploads/ai/` 已在 `.gitignore` 中，真实 Key 不会进仓库。

## 二、网站怎么逛

### 首页九屏

首页是一套自写的整屏翻页，一次手势翻一屏。右侧圆点导航的提示条按屏换色。

| 屏 | 锚点 | 屏名 | 你能做什么 |
|---|---|---|---|
| 1 | `#page1` | 皮影工厂 | 在输入框问一句，答案就地展开；点三个快捷问法；答案下方可进影窗问答 |
| 2 | `#page2` | 影藏 | 六张竖条卡片点开著录纸片；右下「查看更多」进影藏页 |
| 3 | `#page3` | 影史 | 点汉 / 唐 / 宋 / 元 / 明清 / 近现代六个朝代切换说明；曲线随指针吸附 |
| 4 | `#page5` | 流派地图 | 点地图红点或省份看当地影系详情；「回到全国」、左右箭头切换、Esc 复位 |
| 5 | `#page7` | 经典剧目 | 戏单点选五峰会 / 镇冤塔 / 白蛇传 / 西游记；点「听一段」播放高潮音频，唱词随起唱点逐句点亮 |
| 6 | `#page4` | 影讯 | 头条 / 速览 / 现场三栏，点卡片展开全文纸层，Esc 或点纸外关闭 |
| 7 | `#page8` | 工序 | 六列竖卡随进场逐条点亮：选皮 / 描样 / 雕刻 / 上色 / 缀结 / 整平 |
| 8 | `#page6` | 传承 | 悬停或 focus 五位传承人换图，点击展开生平；「查看其他传承人」返回 |
| 9 | `#page9` | 关于 | 站内导航与版权信息 |

首页第 2 屏的六件实物顺序与影藏页一致：**头茬 → 砌末 → 衬景 → 坐骑 → 身段（连头身段）→ 戳子**。

| 方式 | 操作 |

| 滚轮 | 向下滚一屏、向上滚一屏，一次手势只翻一屏 |

## 三、功能使用指南

### 3.1 影窗问答

「影窗」是本站 AI 问答的叫法，有两个入口。

**首屏就地问答**：在首页第一屏输入框里打字并回车（最多 120 字），答案在输入框下方逐字展开，不跳页。输入框下有三个快捷问法可以直接点。答案下方的「接着说，进影窗问答 →」会带着问题跳到完整对话页；`Esc` 收起答案。

**影窗问答页 `chat.html`**：

- 底部输入框回车发送，`Shift + 回车`换行（最多 300 字）。
- 回答下方可点「追问」直接发出。
- 「新开一窗」清空会话，「回影窗」返回首页。
- 会话存在浏览器本地，换页不丢，关闭标签页清空。
- 从首屏带 `?q=` 进来会自动发问。

回答先走后端 `/api/assistant`，接口不通时回落到内置 16 条皮影知识库，所以只打开静态页也能对话。

### 3.2 影偶制作

`craft.html` 从一句话生成一只影偶。

1. **选流派**：六路流派选一路。
2. **定行当**：六大门类、每门三个细行。
3. **说一句**：描述你想要的影偶（最多 120 字）；点「换一个例子」随机填一句。
4. **摆架子**：亮相 / 静立 / 疾走 / 开打 / 施礼 / 回眸。
5. 点 **「落 笔」**（或回车）提交，出图约 15～30 秒。

出图后可用工具栏切换可动 / 整图，选动作（站定 / 行礼 / 走台 / 开打），点「校准关节」调整；结果区可「再画一张」「存到本地」「复制提示词」「改一句再画」。

「画过的」墙保存在浏览器本地，最多 18 张，可点开看大图、单张删除或清空。服务端限制每个用户每分钟最多出图 5 次。

> 出图需要智谱 CogView 的 Key。没配 Key 会明确提示「绘画还没配好」，不会一直转圈。

### 3.3 戏影社区

`community.html` 的数据存在服务端，多台设备看到的是同一份内容。路由结构：`#/` 广场 → `#/c/<吧id>` 吧内 → `#/t/<帖id>` 楼层。

**开吧**：广场点「＋开个吧」，需先登录。填吧名（2～12 字）、印章字（1 字）、分区、简介（≤40 字）后发布，**开吧者自动成为吧主**。分区有六个：影偶制作、唱腔念白、流派考据、晒件、问答求助、棚内杂谈。

**普通成员**：

- 吧头点「＋ 加入本吧」成为成员，再点一次退出；吧主不能加入。
- 点「签到」每天一次，纯本地记录；连续签到累计等级。
- 点「＋发表新帖」：标题 ≥4 字，正文 ≥10 字，可加最多 3 个标签。
- 楼层里可点赞（再点取消）、回复（自动填「回 XXX：」）、勾「只看楼主」。
- 作者可删自己的帖；吧主可删本吧任何帖。删除需要二次确认。

**吧主专属**：吧头多出「改吧的信息」和「删掉这个吧」。前者修改吧名 / 印章 / 分区 / 简介，后者需连点两次确认，会把吧和帖子一起删掉。服务端会再次校验吧主身份。

帖子工具条提供三类 tab（全部主题 / 我发的 / 有回复）、排序（按最后回复 / 发帖时间 / 回复多少）、吧内搜索和分页（每页 8 条）。

### 3.4 账号与个人中心

`login.html` 有两个页签：登录、注册（`?tab=register` 直达注册）。

- **注册**：邮箱 + 图形验证码 + 邮箱验证码（6 位，60 秒冷却）+ 密码（≥6 位）。
- **登录**：邮箱或用户名 + 密码 + 图形验证码；点验证码图片可换一张。评审可直接用文首的测试账号 `a1`。
- **找回**：`reset` 流程用邮箱验证码重置密码。

`profile.html` 需登录才能进，包含：

- 名帖：昵称、handle、打码邮箱、入班日期、个性签名。
- 个性签名：点五条预置签语，或自己写（≤24 字）。
- 我的皮影墙：来自本机的出图记录，可「灯下看」、存到本地、从墙上取下。
- 我在社区：我的圈子 / 我发的帖 / 我回的楼。
- 账号设置：改昵称、改密码（改后其他设备的登录失效）、退出登录。邮箱暂不支持换绑。

邮件验证码需要 SMTP 配置。未配置时可用 `QN_MAIL_MODE=log`，验证码写入 `server/data/mail.log`，接口会返回 `dev:true`。

### 3.5 浏览型页面的小技巧

- **影藏六器**：转盘自动轮播，鼠标悬停满 2.4 秒暂停；也可用左右箭头、键盘 ←→、触摸滑动切换。下方藏品影像录按「类别 → 地域 → 行当 / 细类」三级筛选，点任一张开著录弹层，含上一帧 / 下一帧。
- **经典剧目**：点「听一段」播放真实音频，唱词按真实起唱点逐句点亮；翻走该屏会自动停播。
- **流派地图**：点红点或省份推近镜头，右栏显示材质、操纵杆、尺寸、唱腔、造型、伴奏与考据；`Esc` 回全国视图。
- **影史**：时间轴细线可以直接拖动，键盘 ←→ 也能切换时期。
- **传承**：四个维度按钮切换不同视图，四批传承人名录点开看名单。

## 四、常见问题

**问答没反应 / 答非所问**：先确认后端已启动。未配 DeepSeek Key 时首屏只给错误提示，完整对话页会自动回落到内置知识库。想接真模型按[配置说明](#配置与环境变量)填 Key。

**出图失败**：检查智谱 Key 和余额；描述里少提兵器、血腥等敏感内容；高峰排队请稍后再试。接口失败会给出具体原因。

**收不到邮件验证码**：未配 SMTP 时接口返回 503，注册页会收起邮箱验证码格。开发时设 `QN_MAIL_MODE=log` 并查看 `server/data/mail.log`。

**社区登录后还是不能发帖**：开吧和发帖都要求登录态，确认没有清掉 `qn_sid` Cookie。吧主操作只有开吧者本人可用。

**个人中心社区统计是空的**：`profile.js` 读的是浏览器本地旧键，社区主数据已在服务端。这是已知问题，不影响社区本身使用。

**音频拖不动 / 放不出来**：本地请通过 `server/dev.js` 访问，它支持 HTTP Range；直接双击 HTML 或用其他静态服务器可能无法拖动进度。

## 五、给开发者

### 技术与目录

前端零框架、零打包、零 CDN，13 个 HTML 页面共用 `assets/css/`（18 个样式）与 `assets/js/`（脚本按模块拆开），靠 `?v=` 版本号破缓存。后端是单文件 Node，用原生 `http.createServer`，JSON 文件库，不需要数据库服务。

```
.
├── index.html                    首页（九屏纵向影像志）
├── eras / atlas / repertoire / dispatch / process / lineage / vault.html
├── community / chat / craft / login / profile.html
├── assets/
│   ├── css/                      token → layout → site → 页面级
│   ├── js/                       deck / reveal / ask / chat / studio / community 等
│   ├── img/                      bg craft eras hero lib logo map mat news parts people roles
│   └── fonts/
├── server/
│   ├── server.js                 后端 API（JSON 文件库）
│   ├── dev.js                    本地开发服（静态 + /api 反代，支持 Range）
│   ├── config/                   密钥配置（*.json 不入库，只留 *.example.json）
│   └── data/                     运行时数据
├── docs/                         文档
├── 文档/                         视频分镜、解说词、字幕与使用说明
└── uploads/ai/                   AI 生成的影偶图
```

几个实现要点：

- **整屏翻页**：`translate3d` + 缓动，滚轮 / 键盘 / 触摸 / 圆点 / 锚点统一进一个 `go()`，动画未结束锁输入。
- **进场动效**：CSS 变量 `--rv-y` 控方向、`--rv-d` 控错位延迟；`prefers-reduced-motion` 全量降级。
- **提示条**：宽度 `auto` + `clip-path` 擦除动画，长屏名不裁字。
- **图片处理**：裁切、圆角、压缩用无头 Chrome 的 canvas 完成，不引入图像库。

### 配置与环境变量

配置查找顺序：`QN_*` 环境变量优先，其次 `server/config/*.json`，找不到再回退 `/etc/qnyx/*.json`。对应环境变量：

| 变量 | 作用 |
|---|---|
| `PORT` / `DEV_PORT` / `API_PORT` | 后端端口 / 前端端口 / 前端反代目标端口 |
| `QN_DEEPSEEK_MODE=mock` | 说戏人返回占位回答，不调真实模型 |
| `QN_DEEPSEEK_KEY` / `QN_DEEPSEEK_CONFIG` | DeepSeek Key / 配置文件路径 |
| `QN_ZHIPU_MODE=mock` | 出图返回空 URL，前端显示「这张没取回来」 |
| `QN_ZHIPU_KEY` / `QN_ZHIPU_CONFIG` | 智谱 Key / 配置文件路径 |
| `QN_MAIL_MODE=log` | 邮件验证码写日志，不真正发信 |
| `QN_MAIL_CONFIG` | 邮件配置文件路径 |
| `QN_DATA` | JSON 库落盘路径，如 `/var/lib/qnyx/db.json` |
| `QN_UPLOAD` | AI 出图落盘目录，必须与站点静态目录一致 |

无 Key 时的行为：

| 场景 | 表现 |
|---|---|
| `/api/assistant` 无 Key | 返回 503，聊天页回落内置 16 条知识库，首屏给出对话页入口 |
| 生图无 Key | 返回 503「绘画还没配好」 |
| `QN_ZHIPU_MODE=mock` | 出图返回空 URL，**不会真的出图** |
| 未配 SMTP 且未设 log | 邮件验证码返回 503，图形验证码接口回 `mail:false` |

### 部署

阿里云 ECS（Ubuntu 22.04.5 LTS）+ nginx 直出静态文件，`/api/` 反代到 `127.0.0.1:3100`，后端由 systemd 单元 `qnyx.service` 托管，Node.js 20。Key 放 `/etc/qnyx/`（`600 www-data`）。

systemd 单元里两个路径型环境变量必须设对，否则会出现「接口通但读不到配置 / 出图在页面上看不见」：

| 变量 | 值 | 作用 |
|---|---|---|
| `QN_DATA` | `/var/lib/qnyx/db.json` | JSON 库落盘位置 |
| `QN_UPLOAD` | `/var/www/html/uploads/ai` | AI 出图落盘目录，必须与静态目录一致 |

当前线上：主站 `120.55.204.70`，备用站 `121.41.66.240`（同版本快照，可切换）。

## 七、已知限制

- 数据层是 JSON 文件，适合演示与小规模使用，并发写入需换数据库。
- AI 出图依赖第三方接口，高峰期可能排队；失败会明确提示，不会静默卡住。
